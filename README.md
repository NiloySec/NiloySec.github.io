# NiloySec Portfolio — OSINT Research & Cybersecurity

Static, responsive portfolio for Md Kamrujjaman (NiloySec), focused on public-source OSINT research, digital investigations, evidence-led reporting, and cybersecurity learning.

## Files
- `index.html` — semantic portfolio content, SEO metadata, structured data, project showcase, education, reviews, and contact links
- `style.css` — responsive dark-navy / teal design system and page styles
- `script.js` — mobile navigation, footer year, and terminal type/erase animation
- `profile.webp` — optimized portrait used on the page
- `profile.png` — original portrait used for social preview metadata
- `cv.pdf` — downloadable CV
- `favicon.svg` — browser icon
- `robots.txt`, `sitemap.xml`, `.nojekyll` — GitHub Pages and search-engine support

## Deploy to GitHub Pages
1. Back up or commit the current repository first.
2. Extract this ZIP and open the `niloysec-portfolio` folder.
3. Copy the folder contents (not the outer folder) to the repository root, replacing matching website files.
4. Commit and push to the configured publishing branch.
5. Wait for the GitHub Pages deployment to finish, then test the live site.

## Before calling the site production-ready
Check all links, CV download, mobile layouts (320–430 px), keyboard focus/navigation, image alt text, contrast, page title/description, and Lighthouse performance/accessibility. A perfect score cannot be promised without running those tests against the deployed site.
