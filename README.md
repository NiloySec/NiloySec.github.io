# NiloySec Portfolio — OSINT / Cyber Intelligence Edition

Static personal portfolio for Md Kamrujjaman (NiloySec), focused on OSINT research, digital investigations, and cybersecurity learning.

## Design direction
- Dark analyst-workstation aesthetic with subtle grid, intelligence-network visual, radar/HUD details, and teal/lime signal accents.
- Professional portrait remains the primary personal identity visual.
- Case studies are clearly labeled as illustrative methodology examples, not claimed client outcomes.
- Client names, earnings, order counts, and confidential case details are intentionally excluded.

## Files
- `index.html` — complete portfolio content and semantic structure
- `style.css` — responsive visual system and OSINT/cyber styling
- `script.js` — mobile navigation interaction
- `profile.webp` — optimized portrait used on the page
- `profile.png` — original portrait used for social preview metadata
- `favicon.svg` — browser icon
- `robots.txt` and `sitemap.xml` — basic search-engine files
- `case-study.pdf` — portfolio methodology document
- `.nojekyll` — GitHub Pages configuration

## Publish to GitHub Pages
Upload the contents of this folder to the repository root, replacing same-named website files and adding new files. Keep any unrelated repository files that are still needed. Commit to the configured publishing branch and verify the deployment in GitHub Actions.

## Verification
This is a static HTML/CSS release. After publishing, test live desktop and mobile layout, external links, keyboard navigation, contrast, and Lighthouse performance/accessibility. No claim of a perfect score is made before live testing.
